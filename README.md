## 🔥 Kaif Ansari's Flagship Projects

### 🤖 [J.A.R.V.I.S. OS Agent](https://github.com/thekaifansari01/Jarvis-OS-Agent)
**The Ultimate Open-Source Autonomous AI Assistant for Windows**  
A desktop-native AI Operating System developed by Kaif Ansari that rivals Claude Code. It features a dual-engine AI (FastBrain + AgenticBrain), **Lifelong Episodic Memory (LTM)**, Hybrid RAG, and Zero Line-Drift Code Editing. Controls Android phones via ADB and your PC remotely via Telegram.

**Key Capabilities:**
- 🧠 Long-term Memory (ChromaDB + Vector Semantic Graph)
- ⚡ Proactive AI with HITL (Human-In-The-Loop) Safety
- 📅 Google Calendar & Gmail Pub/Sub Automation
- 💬 WhatsApp & Telegram Integration
- 🎤 Voice-First Interaction (Deepgram + Edge TTS)
- 🖥️ Full System Automation (Win32 API)
- 🔌 Multi-LLM Auto-Failover (Groq, Gemini, Regolo, OpenRouter)

### 🌐 [Nexus AI (Full Platform)](https://github.com/thekaifansari01/NexusWeb)
**Self-Hosted AI Assistant Platform with Enterprise Security**  
A turn-key platform by Kaif Ansari that transforms any website into a conversational knowledge base. Features a secure proxy, encrypted Groq API keys, and a full dashboard for key management and domain whitelisting.

**Key Capabilities:**
- 🔑 Vault‑Grade Security (AES-256 encrypted Groq keys)
- 🌍 Domain Whitelisting (up to 10 domains per key)
- 🧩 Zero‑Friction Integration (single `<script>` tag)
- 👤 Google OAuth + HttpOnly Secure Cookies
- 📊 Real‑time Dashboard with usage analytics
- ⚡ Python Serverless Functions (Vercel) + Firebase

- 🧠 Smart IndexedDB Caching (24-hour TTL)

- 🖼️ File Attachments & Markdown Rendering

### 🐍 [kairos.ai](https://github.com/thekaifansari01/kairos.ai)
**AI Coding Workspace with Live Python & RAG**

**Key Capabilities:**
- 💬 Multi‑Model Chat (Llama, Gemini, Qwen, Nemotron)
- 🐍 Live Python Execution (Pyodide in Web Workers)
- 📁 Local RAG Pipeline (MiniLM embeddings + IndexedDB)
- ☁️ Cloud Sync (Firestore with Google Login)
- ✏️ Advanced Message Actions (Edit, TTS, Regenerate)
- 🔐 Cybersecurity Lens (Vulnerability awareness prompts)
